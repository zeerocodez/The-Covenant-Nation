# 🌟 TCN Children Church Check-In System (Uyo)

A safe, simple, and high-end children attendance and management system designed for **The Covenant Nation, Uyo**.

## Features

- **📊 Dashboard**: Real-time counters for currently checked-in children, total registered children, and upcoming birthdays this week.
- **✅ Check In/Out Desk**: Fast live search with 1-click check-in and secure check-out.
- **📝 New Child Registration**: Form with automatic age computation from Date of Birth, emergency contacts, and special medical/allergy notes.
- **🎂 Birthday Reminders**: Real-time categorization into Today's Birthdays, This Week's Birthdays, and Upcoming Birthdays This Month.
- **📈 Sunday Attendance Summary**: Service metrics, 4-week moving averages, attendance history table, and CSV export.
- **👩‍🏫 Teachers on Duty**: Teacher registration, live duty check-in, on-duty monitor, and directory.
- **🛡️ High-End UI**: Premium heraldic crest of The Covenant Nation, responsive hero section, and emergency hotline bar.

## Technology Stack

- **React 19**
- **TypeScript**
- **Vite 6**
- **Tailwind CSS 4**
- **Lucide React**
